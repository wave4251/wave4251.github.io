# 武川个人网站 · 交付说明

> 《且将新火试新茶，诗酒趁年华》 V6（暖白纸 + 杏褐 + 雾面莫兰迪）
> 核心表达：我想亲自看看世界，也想亲手参与世界。

纯静态单页网站（HTML + CSS + 原生 JS），零依赖、数据驱动、开箱即用。

**V6 视觉基调**：对齐你提供的 `wuchuan_personal_website_preview.html` 参考配色——暖白纸 `#F7F6F2` + 杏褐 `#B87859` 强调 + 雾面蓝/丁香紫/鼠尾草绿/蜜桃的低饱和莫兰迪色块。全站覆盖细腻噪点纹理、漂浮柔光团、orb 球体、雾面渐变，柔和朦胧、克制不花哨。**去掉了此前的黄绿/高饱和色。**

## 五、素材替换清单

### 照片类（放入对应目录即可）
1. **作品封面/截图**：`images/works/` → 在 `data/projects.js` 各项目填 `cover` 字段
2. **旅行照片**：`images/travel/<城市拼音>/` → 在 `data/travel.js` 填 `src/date/location/caption`（当前 6 城：上海/成都/武汉/长沙/泰安/丽江）

### 文字类
- 旅行照片的记忆句、日期、地点
- NOW 区内容
- 个人说明书/面试记录/Skill 的交付物链接（可选）

## 八、项目结构

```
├── index.html          # 单页入口
├── css/
│   ├── tokens.css      # 设计 token（配色/字体/间距，整站维护入口）
│   ├── base.css        # reset、导航、按钮、噪点、柔光团
│   └── sections.css    # 各章节专属样式
├── js/
│   ├── main.js         # 导航/抽屉/滚动/reveal/视差
│   ├── render.js       # 作品与实践渲染
│   └── gallery.js      # 照片墙 + 城市定位 + lightbox
├── data/
│   ├── projects.js     # 三个作品数据（顺序：招募→星火→析肤）
│   ├── practice.js     # 实习实践数据
│   └── travel.js       # 旅行照片数据（6 城市）
└── images/
    ├── works/          # 作品封面
    └── travel/         # 旅行照片（按城市拼音分目录）
```
